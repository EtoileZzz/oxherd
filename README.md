## 📖 简介 (Overview)

**oxherd**（牧牛者 / 细致守护者）是一款专为楼宇巡查、图书馆值班、机房巡检及安保执勤设计的现代 Android 原生打卡应用。

应用遵循**离线优先（Offline-First）**架构，界面完全对齐工业级 **Fluid Motion 流体物理动效设计规范**，提供高帧率物理阻尼手势、无重排容器几何形变与沉浸式专人专岗体验。

---

## ✨ 核心特性 (Key Features)

### 1. 专人专岗与无干扰打卡
- **设置中自由切换岗位**：彻底废除主屏易误触的横向翻页。值班人员在「设置」中选择自己负责的岗位/楼层（如“3楼自习区”、“4楼阅览室”、“5楼特藏室”），主界面即刻沉浸式展示该点位的检查项。

### 2. 流体物理动效系统 (Fluid Motion Design System)
- **15 组非线性三阶贝塞尔曲线**：以 `EaseQuint` (`cubic-bezier(.18, 1, .28, 1)`) 为主曲线，配合 `EaseExpo`、`EaseSoft`、`EaseSpring`、`EaseBack` 等。
- **废除水波纹，实心瞬时高光 (`flashButton`)**：92% 纯白 + 8% 主题色的实心均匀高光（前 12% 时间达 0.30 峰值，后 440ms 平滑衰减）。
- **连续胶囊滑块状态机 (`slidePill`)**：岗位单选与设置分段控制支持初次挂载 0ms 落位、切项 360ms `expo` 滑动与连续变向续播。
- **阻尼滑动打卡 (`swipeToComplete`)**：64dp 触感吸附震动、文字动态划线（0% $\to$ 100% 伸展），配合 340ms `quint` 容器真实几何补间（Freeze-Inner）零重排收缩。
- **长按蓄力物理微交互 (`dangerHold`)**：高危重置操作需 2000ms 蓄力充满，中途松手 160ms 快速回弹。
- **三档性能降级引擎**：设置中自由调节 `FULL` (完整)、`LITE` (标准)、`MIN` (极速) 档位。

### 3. 时间线性与非时间线性任务自由组合
- **⏱️ 时段巡查 (时间线性)**：绑定具体时间窗口（如 `20:00~20:30 开馆巡查`），处于时段内时呼吸微光高亮指引。
- **📋 常规待办 (非时间线性)**：随时可检查项，支持随时右滑打卡。
- **多层级树状清单**：支持条目展开子项（如：检查消防栓铅封、电源插座通电），子项完成自动联动父项完成。

### 4. 周期排班与精准通知唤醒
- 支持设置周期排班规则（如：每周四晚 20:00 开始）。
- 通过 Android 原生 `ExactAlarmManager` 配合通知权限，在值班前（提前 15 分钟/准点）发出高优先级通知。
- 点击通知一键唤醒应用，直达值班打卡操作界面。

### 5. 拍照凭证智能归类与自动 ZIP 打包归档
- **规范化照片索引**：巡查拍照自动按照「任务/日期/岗位/条目」规范命名和分目录落盘。
- **免翻相册「凭证抽屉」**：交班弹窗内集成凭证抽屉，按岗位分类展示现场缩略图，支持一键多选直接分享发送到腾讯 TIM、微信或表单上传。
- **自动 ZIP 归档与周而复始**：确认交班瞬间，底层自动将「文字日报摘要（`report.txt`）」、「全部分类凭证照片（`photos/`）」以及「结构化元数据（`metadata.json`）」**无损压缩打包为独立 `.zip` 归档文件**（保存在 `context.getExternalFilesDir("archives")`）；随后自动重置复位当前任务并排定下次值班，形成周而复始的自动化闭环。

## 🛠️ 技术架构 (Tech Stack)

| 层次 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **编程语言** | Kotlin 2.0+ | 协程、Flow 响应式数据流 |
| **UI 框架** | Jetpack Compose (BOM) | Material 3 + Fluid Motion 自研动效系统 |
| **持久层** | SQLiteOpenHelper (原生响应式) | 极速秒开、零 KSP 编译依赖、事务一致性保证 |
| **后台调度** | AlarmManager + BroadcastReceiver | 准点定时任务与精准通知触达 |
| **文件归档** | Java NIO ZipOutputStream | 本地流式无损打包压缩 |
| **构建体系** | Gradle 9.1 + AGP 9.0 | 模块化架构，极速增量编译 |

## 🚀 编译与运行 (Build & Run)

### 前置环境
- JDK 17 或 JDK 21
- Android SDK (API Level 26 ~ 36)

### 常用命令
```bash
# 1. 运行所有单元测试
./gradlew testDebugUnitTest

# 2. 编译生成 Debug APK
./gradlew assembleDebug

# 产物路径: app/build/outputs/apk/debug/app-debug.apk
```
